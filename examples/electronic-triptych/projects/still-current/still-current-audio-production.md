# Still Current

32 秒，自由時間、無鼓；D major。60 BPM 僅為 MIDI 參考速度，不代表週期拍點。

音色來源：Original additive cloud voices, slow harmonic amplitude modulation and filtered generated noise; no drums, samples or field recordings。

WAV 母帶：48kHz、24-bit、立體聲，-19.8 LUFS。
AAC：-19.8 LUFS、-10.3 dBTP；完整解碼無錯誤。

MIDI 保存各聲部音符；預設 GM 音色與完成版合成器不同。分軌若有輸出，為共同增益的浮點 premaster，可用於重新混音。

音符與訊號檢查用來排除製作錯誤；音樂的主觀聽感需實際播放判斷。本檢查不代表已試聽。
